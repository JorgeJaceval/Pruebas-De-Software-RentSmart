# RentSmart

Somos Jorge Aceval y Joaquín Viveros. Desarrollamos un proyecto académico de **arriendo de espacios entre particulares** para el curso de Pruebas de Software.

Nuestro objetivo es conectar personas que ofrecen espacios con quienes necesitan arrendarlos, construyendo una aplicación respaldada por pruebas automatizadas.

## Equipo

- **Jorge Aceval:** líder de equipo y responsable de backend e integración; coordina entregas, administra GitFlow, desarrolla FastAPI/SQLModel/PostgreSQL y mantiene Pytest y GitHub Actions.
- **Joaquín Viveros:** responsable de frontend y pruebas de interfaz; desarrolla React/TypeScript/Vite, integra la API y mantiene Jest, React Testing Library y Playwright.

Entre ambos mantenemos la documentación, verificamos los criterios de aceptación y revisamos los pull requests del otro.

Coordinamos el trabajo por **Discord** y gestionamos historias, criterios y pruebas en **Jira**. El equipo de dos integrantes cuenta con autorización docente.

## Tecnologías y trabajo

Desarrollamos el frontend con React, TypeScript y Vite, y el backend con FastAPI y Python. Usamos PostgreSQL y SQLModel para la persistencia. Probamos con Jest, React Testing Library y Pytest, y ejecutamos nuestro pipeline con GitHub Actions. Reservamos las pruebas E2E con Playwright para la entrega 3.

Trabajamos con GitFlow y revisiones mediante pull requests. El MVP incluye registro y sesión, gestión CRUD de espacios, catálogo, búsqueda básica, detalle, horario y creación de reservas. El alcance futuro contempla reservas recibidas, disponibilidad temporal en el catálogo, cancelación, pago simulado, IA y administración.

La Entrega 1 incluye el [video de presentación](https://drive.google.com/file/d/17H2e4SKm3GOre0F0W0TxGIGKeGdF53n1/view?usp=sharing), la versión [`v1.0-entrega1`](https://github.com/JorgeJaceval/Pruebas-De-Software-RentSmart/releases/tag/v1.0-entrega1) y sus [notas de versión](https://github.com/JorgeJaceval/Pruebas-De-Software-RentSmart/blob/main/docs/releases/entrega-1.md). La evidencia de pruebas registra 98 comprobaciones Jest y 114 Pytest aprobadas; los 99 CP lógicos documentados se cuentan por separado y mantienen tres casos planificados.
