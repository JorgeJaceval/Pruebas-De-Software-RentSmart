# RentSmart

Somos Jorge Aceval y Joaquín Viveros. Desarrollamos un proyecto académico de **arriendo de espacios entre particulares** para el curso de Pruebas de Software.

Nuestro objetivo es conectar personas que ofrecen espacios con quienes necesitan arrendarlos, construyendo una aplicación respaldada por pruebas automatizadas.

## Tecnologías y trabajo

React, TypeScript y Vite; FastAPI y Python; PostgreSQL y SQLModel. Pruebas con Jest, React Testing Library, Pytest y Playwright. CI/CD previsto con GitHub Actions.

Trabajamos con GitFlow y revisiones mediante pull requests. La aplicación se encuentra en su etapa inicial de desarrollo.
