# HU-08 — Explorar el catálogo (REN-8)

Como persona interesada en arrendar, quiero explorar un catálogo de espacios publicados para conocer la oferta disponible.

Fuente: `Historias de usuario.pdf`, pp. 11–12; RN-01, p. 2, y RN-14, p. 3. Tarea: [REN-8](https://rentsmartpsf.atlassian.net/browse/REN-8). Depende de HU-03 y HU-05.

## Comportamiento y alcance

Desde **Explorar catálogo** abrimos `#catalogo` sin iniciar sesión. Las tarjetas muestran nombre, foto principal, tipo, comuna, capacidad y precio por hora en CLP. Consultamos solo publicaciones activas no retiradas y reemplazamos una foto externa que no cargue.

Distinguimos carga, lista vacía y error de consulta. Los fallos permiten reintentar; una respuesta inválida no se interpreta como una lista vacía. Renovamos la consulta al volver al catálogo y descartamos resultados después de abandonar la vista.

Explicamos que ver una publicación no garantiza disponibilidad para una fecha y hora. Mostramos el conjunto pequeño de demostración completo, sin paginación ni capacidad masiva declarada. Los filtros pertenecen a HU-09.

El enlace de cada tarjeta abre `#detalle-espacio/{id}` con un resumen público de los mismos datos básicos. La consulta por identificador comprueba la visibilidad actual; una URL antigua no expone un espacio desactivado, retirado o eliminado. Verificamos los seis campos y el enlace funcional de CA-02; el detalle completo de HU-10 continúa pendiente.

## Contrato y verificación

Reutilizamos `GET /api/spaces`. Añadimos `GET /api/spaces/public/{id}` como lectura mínima para el enlace, con el DTO de datos publicables existente. Ambas consultas son públicas y no incluyen propietario, correo ni banderas administrativas. La interfaz conserva únicamente los campos que utiliza.

La lectura individual devuelve `200` para un espacio visible, `404` para inexistente/inactivo/retirado, `422` para UUID inválido y `503` ante fallo SQL. Conservamos mensajes controlados y `Cache-Control: no-store`. No necesitamos migraciones ni nuevos servicios.

Probamos lecturas, visibilidad, privacidad, vacío y fallos con Pytest/FastAPI TestClient y PostgreSQL real en esquemas aislados. Probamos tarjetas, acceso público, estados, fotos, navegación y reintento con Jest/React Testing Library y HTTP simulado. Registramos seis CP y sus resultados en **CP**, **Testing** de REN-8 y el PR; reservamos las E2E para entrega 3.
